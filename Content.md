# `COURSE_WEBSITE_CONTENT_GUIDELINES.md`

## 1. Project Overview

This website is an **online learning platform** offering practical courses across:

* Language & Communication
* Career Development
* Technology
* Creative Skills
* Everyday Life Skills

The platform uses a structured learning model:

**Category → Course → Skill Level**

Each course can have the following four levels:

* Beginner
* Intermediate
* Advanced
* Expert

The content should make this progression clear without making the website feel complicated.

---

# 2. Current Course Categories

Use the supplied category data as the source of truth.

### Talk & Connect

Language and communication skills for everyday conversations, travel, study, and work.

### Career Boost

Professional skills covering workplace communication, teamwork, leadership, marketing, interviews, business, and career development.

### Tech Up

Practical technology learning covering coding, artificial intelligence, digital tools, data, cybersecurity, and related technology subjects.

### Creative Hub

Creative learning covering illustration, design, photography, video, writing, digital art, and related creative subjects.

### Life Skills

Practical everyday learning covering areas such as cooking, personal finance, productivity, travel, wellness, hobbies, and useful everyday knowledge.

Do not invent additional categories unless the user specifically provides them.

# 3. Course Structure

Courses belong to a category and can contain different learning levels.

The actual course list and course-to-category relationships must come from the supplied course data.

* What the learner will study.

* What the learner should be able to do afterward.

---

# 4. Skill Levels

The platform uses exactly four skill levels:

### Beginner

Designed for learners who are new to the subject or want to establish a reliable foundation.

Content should focus on:

* Core concepts.
* Basic terminology.
* Simple techniques.
* Guided practice.
* Fundamental understanding.

### Intermediate

Builds on foundational knowledge.

Content should focus on:

* Stronger practical application.
* More varied situations.
* Greater independence.
* Deeper understanding.
* More structured practice.

### Advanced

Designed for learners who already understand the fundamentals.

Content should focus on:

* More complex situations.
* Refined techniques.
* Problem-solving.
* Practical application.
* More independent work.

### Expert

Designed for learners seeking a high level of independent application.

Content should focus on:

* Advanced decision-making.
* Complex application.
* Refinement.
* Independent planning.
* Professional or sophisticated use where appropriate.

Do not imply that completing a level automatically makes someone professionally qualified unless the course explicitly provides such certification.

---

# 24. STRICT Translation Key Replacement Rule

**Never reuse an old translation key for newly rewritten content.**

When rewriting a page:

1. Identify existing keys.
2. Create completely new keys for the new content.
3. Replace the old frontend references.
4. Check where the old keys are used.
5. Delete the old keys once confirmed unused.
6. Add the new keys to all required languages.
7. Verify there are no references to deleted keys.

### Good

```text
course_hero_heading
course_hero_description
course_level_heading
course_learning_summary
course_outcomes_heading
course_enrollment_action
```

### Bad

```text
text1
title2
buttonA
content_new
course_text
```

Do not place new content inside old keys.

**New content = New keys.**

**Old unused keys = Delete.**
